# 数据库设计文档（大纲）

> 本文为模板，待团队填充 ER 图与字段定义。

## 1. 核心实体
- **患者 Patient**：患者主索引（EMPI）、基本信息、风险因素
- **风险评估 RiskAssessment**：评分、等级、建议、时间
- **病历 MedicalRecord**：主诉、检查、诊断、方案（诊中）
- **MDT 会诊 MdCase**：成员、讨论、共识结论
- **用药提醒 Medication**：药物、剂量、时间
- **随访 FollowUp**：复查计划、症状日志、预警

## 2. 关系示意
```
Patient 1—* RiskAssessment
Patient 1—* MedicalRecord
Patient 1—* Medication
Patient 1—* FollowUp
MedicalRecord 1—* MdCase
```

## 3. 合规要求
- 患者敏感字段加密存储
- 访问分级授权 + 审计日志
- 满足《个人信息保护法》与医疗卫生机构网络安全要求
