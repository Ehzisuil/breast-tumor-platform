# 产品需求文档（PRD）大纲

> 本文为模板，待团队填充具体需求与验收标准。

## 1. 产品定位
乳腺肿瘤全周期（诊前-诊中-诊后）智能管理平台，目标用户为患者与医护协作方。

## 2. 用户角色
- 患者 / 家属
- 医生（乳腺外科、肿瘤内科、放疗科…）
- 管理员

## 3. 功能需求

### 3.1 诊前
- [ ] AI 风险评估：多因素加权模型 / 机器学习模型
- [ ] 科普与健康教育：结构化知识库
- [ ] 乳腺自查指南：步骤化引导
- [ ] 预约筛查：对接机构排班

### 3.2 诊中
- [ ] 智能分诊：主诉 → 科室 / 紧急度
- [ ] 电子病历（EMR）：结构化采集与共享
- [ ] MDT 多学科会诊：在线协同与共识生成

### 3.3 诊后
- [ ] 术后康复：个性化计划
- [ ] 用药提醒：定时推送
- [ ] 复发监测：随访 + 症状日志 + 预警
- [ ] 心理疏导：量表 + 自助 + 转介

## 4. 非功能需求
- 性能、可用性、安全性、合规（等保 / 个人信息保护）
