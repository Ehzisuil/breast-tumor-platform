# 架构设计文档（大纲）

> 本文为模板，待团队填充。

## 1. 总体架构
前端（Web / 小程序）— 后端 API（FastAPI / NestJS）— 数据层（PostgreSQL + 对象存储）。

## 2. 分层
- 接入层：CDN / 网关 / 反向代理（Nginx）
- 应用层：业务微服务 / 单体 API
- 数据层：关系库 + 缓存 + 文件存储
- AI 层：风险评估 / 分诊 / 科普生成模型

## 3. 三阶段数据流
统一患者主索引（EMPI）串联：诊前风险档案 → 诊中病历 / MDT 结论 → 诊后随访计划。

## 4. 关键设计
- 鉴权：OAuth2 / JWT，角色权限（RBAC）
- 合规：数据加密、分级授权、审计日志
- 集成：对接医院 HIS / LIS / PACS（按需）

## 5. 技术选型
| 层 | 选型 |
|---|---|
| 前端 | React + TypeScript（+ Ant Design / Tailwind） |
| 后端 | FastAPI（Python）/ NestJS（Node） |
| 数据库 | PostgreSQL |
| 部署 | 国内云平台（禁 Vercel / Railway） |
